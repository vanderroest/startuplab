# StartupLab

Bouw stap voor stap je eigen bedrijf – een webapp voor brugklassers.

## Publiceren op GitHub Pages
1. Maak op github.com een nieuwe repository `startuplab` (Public).
2. Kies **uploading an existing file** en sleep alle bestanden uit deze map erin: `index.html`, `startuplab-uitleg.mp4`, `startuplab-poster.jpg` en `README.md`. Klik **Commit changes**.
3. **Settings → Pages**: Source **Deploy from a branch**, branch **main**, map **/(root)**, **Save**.
4. Na 1–2 minuten: `https://<gebruikersnaam>.github.io/startuplab/`. Deel deze link in Teams.

## Belangrijk
- Verander de gebruikersnaam en repositorynaam daarna niet: het werk van leerlingen hoort bij dit webadres.
- Updates: upload een nieuwe `index.html` in dezelfde repository. Bestaand werk blijft bewaard.
- Alles wordt opgeslagen in de browser van de leerling. Laat leerlingen regelmatig een back-up downloaden (menu ☰) en in OneDrive zetten; via “Back-up terugzetten” komt alles terug.
- Er gaat niets naar een server.
